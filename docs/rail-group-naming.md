# 轨道模型分组命名约定（v1）

> 适用范围：`assets/vastseatrain/models/block/rail/*.obj` 中的轨道部件分组（Blender 物体名 = OBJ `o` 名 = Forge 的 OBJ 部件名）。
> **分组名由美术决定，程序只读取、不改名。** 本文件是给美术的命名建议，不是程序修改模型的依据。

## 1. 分组名格式

```text
<类别>_<朝向>_<部件>
```

- 三部分全部小写 ASCII，用下划线分隔，不含空格与数字后缀。
- `<类别>` 固定为 `rail`（轨道）。将来道岔、桥梁等新增类别时另起类别名，不要复用。
- `<朝向>` 表示部件在轨道横断面上的位置，取值见下表。
- `<部件>` 表示部件类型，取值见下表。

## 2. 朝向

| 值 | 含义 |
| --- | --- |
| `center` | 沿轨道前进方向通长、位于轨道中心线（纵向铺开的多件） |
| `left` | 面向前进方向时的左侧 |
| `right` | 面向前进方向时的右侧 |
| `full` | 横向铺满整段轨道宽度（3 格） |

## 3. 部件

| 值 | 含义 | 可复用性 |
| --- | --- | --- |
| `ballast` | 道砟 | 随轨道段重复铺设 |
| `sleeper` | 轨枕 | 一个模型内可含多根，间距由美术保证 |
| `fastener` | 扣件 | 一个模型内可含多组，左右成对由美术保证 |
| `rail` | 钢轨本体 | 左右两根分别命名 |

## 4. 命名对照建议

| 部件 | 建议名称 | 当前导出所用名称 | 说明 |
| --- | --- | --- | --- |
| 道砟 | `rail_full_ballast` | `rail_full_ballast` | 横向铺满轨道宽度，随段重复 |
| 钢轨（左） | `rail_left_rail` | `rail_left_rail` | 轨顶 `y = 0.750` |
| 钢轨（右） | `rail_right_rail` | `rail_right_rail` | 轨顶 `y = 0.750` |
| 轨枕 | `rail_center_sleeper` | `rail_center_sleeper` | 沿前进方向通长的水泥轨枕 |
| 扣件 | `rail_center_fastener` | `rail_center_fastener` | 沿前进方向通长排布的扣件 |

当前导出已全部使用左列名称，程序按这些名称读取。

## 5. 使用规则

- **程序不得修改美术分组名**。需要隐藏某个部件时，在程序侧 JSON 的 `visibility` 里按美术原名引用。
- **两侧补位格**：中心格与左右补位格都渲染同一份模型，允许重叠（美术越界观感）；差异只写在程序侧 JSON 里。
- **道岔与曲线**：道砟、轨枕、扣件、钢轨的分组名保持不变，额外增加方向性部件（如尖轨、辙叉）时按同样格式命名，并在本文件追加对照。

## 6. 交付检查

- [ ] 每个部件都是独立分组，名称符合第 1 节格式。
- [ ] 没有部件同时承载两种含义（例如扣件和轨枕不要合在一个分组里）。
- [ ] 左右部件按面向前进方向判定，不按模型坐标左右判定。
- [ ] MTL 保持纯 ASCII（Forge 按 ASCII 读取，中文注释会让整份材质库解析失败）。
- [ ] 贴图与 MTL 同目录，`map_Kd` 用相对文件名。
