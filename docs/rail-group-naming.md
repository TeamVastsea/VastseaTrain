# 轨道模型分组命名约定（v1）

> 适用范围：`assets/vastseatrain/models/block/rail/*.obj` 中的轨道部件分组（Blender 物体名 = OBJ `o` 名 = Forge 的 OBJ 部件名）。
> 分组名以美术导出为准，程序只读取、不重命名模型内容。

## 1. 分组名格式

```text
<类别>_<朝向>_<部件>
```

- 三部分全部小写 ASCII，用下划线分隔，不含空格与数字后缀。
- `<类别>` 固定为 `rail`（轨道）。将来道岔、桥梁等新增类别时另起类别名，不要复用。
- `<朝向>` 表示部件在轨道横断面上的位置，取值见下表。
- `<部件>` 表示部件类型，取值见下表。

## 2. 朝向

| 值 | 含义 |
| --- | --- |
| `center` | 沿轨道前进方向通长、位于轨道中心线（纵向铺开的多件） |
| `left` | 面向前进方向时的左侧 |
| `right` | 面向前进方向时的右侧 |
| `full` | 横向铺满整段轨道宽度（3 格） |

## 3. 部件

| 值 | 含义 | 可复用性 |
| --- | --- | --- |
| `ballast` | 道砟 | 随轨道段重复铺设 |
| `sleeper` | 轨枕 | 一个模型内可含多根，间距由美术保证 |
| `fastener` | 扣件 | 一个模型内可含多组，左右成对由美术保证 |
| `rail` | 钢轨本体 | 左右两根分别命名 |

## 4. 当前轨道部件对照

| 部件 | 新名称 | 旧名称 | 说明 |
| --- | --- | --- | --- |
| 道砟 | `rail_full_ballast` | `RAIL_BASE_b` | 横向铺满轨道宽度，随段重复 |
| 钢轨（左） | `rail_left_rail` | `RAIL_LEFT_b` | 轨顶 `y = 0.75` |
| 钢轨（右） | `rail_right_rail` | `RAIL_RIGHT_b` | 轨顶 `y = 0.75` |
| 轨枕 | `rail_center_sleeper` | `RAIL_BASE_b1_2` | 沿前进方向通长的水泥轨枕（一个模型内多根） |
| 扣件 | `rail_center_fastener` | `RAIL_BASE_b1_1` | 沿前进方向通长排布的扣件（一个模型内多组） |

## 5. 使用规则

- **变换只作用于部件**：隐藏、平移、翻转只针对单个部件名，不要写整段模型的变换，也不要修改顶点。
- **两侧补位格**：中心格与左右补位格都渲染同一份模型，允许互相重叠（美术越界观感）；补位格与中心格的差异只写在 JSON 里，不改 OBJ。
- **道岔与曲线**：道砟、轨枕、扣件、钢轨的分组名保持不变，额外增加方向性部件（如尖轨、辙叉）时按同样格式命名，并在本文件追加对照。
- **新增部件**必须先登记到第 4 节表格，再由代码引用；未登记的部件代码不得读取。

## 6. 交付检查

- [ ] 每个部件都是独立分组，名称符合第 1 节格式。
- [ ] 没有部件同时承载两种含义（例如扣件和轨枕不要合在一个分组里）。
- [ ] 左右部件按面向前进方向判定，不按模型坐标左右判定。
- [ ] 分组名与本文第 4 节表格一致，新增部件已追加登记。
